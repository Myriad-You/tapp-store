# 联邦五子棋

15×15 自由五子棋 Tapp，支持本地同屏双人和 Myriad 联邦房间联机。黑方先手，无禁手；横、竖或斜线连续五子或更多即胜。

## 联机模型

- 房主创建公开、开放加入、最多 2 人的联邦房间；同实例可使用裸 `room_id`，界面会组合 `room_id@home_server` 供另一位玩家跨实例加入，也可由房主邀请 Actor。
- 房主可在明确确认后调用 `deleteRoom` 解散房间并清除本地恢复状态；普通成员只执行 `leaveRoom`。关闭页面或卸载生命周期不会自动删除联邦数据。
- 消息类型固定为 `gomoku.v1`。客方只发送带随机 nonce 的准备、交换黑白、落子、认输和同步意图；无状态响应时会延迟拉取最新快照，落子确认前禁止重复发送。
- 实时消息按宿主事件的 `ev.data.message` 包装解码，历史消息按直出记录解码；两条路径都只信任消息信封的 `sender_actor`。
- 房主验证消息发送者、座位、当前手番、坐标和空位，然后发布递增序号的完整状态快照。
- 客方通过 `getRoom().owner_actor` 锚定房主身份，仅接受该 Actor 亲自发送、结构合法且序号更新的状态；棋盘会从落子列表重新构建，胜负会重新计算。
- 房间事件按完整房间 ID 隔离；只有宿主省略 home server 时才允许与当前房间的本地 ID 对齐。房主串行处理意图，避免并发准备或落子产生重复序号；成员离座事件会清理大厅座位，对局中离座按认输结算。
- 最近房间状态保存在 Tapp Storage 中，可在页面重开后恢复；房间消息历史用于补齐最新房主快照。
- 联机大厅会封闭棋盘并分别显示黑方、白方的准备状态；双方可在开局前交换黑白，交换后准备状态会重置。再战需双方重新准备并自动交换黑白。对局中落子预览跟随当前手番，非本方回合会常驻显示醒目提示。
- 回合提示使用固定高度占位和淡入动画，出现或消失时不会推动棋盘。右上角身份和双方玩家优先显示联邦资料昵称，完整 Actor 地址保留在元素标题中；资料暂不可用时从 Actor 地址提取用户名降级显示。
- Actor 比较统一规范化协议、主机名和尾部斜杠，同时保留 URL 路径大小写，避免同一身份因表示差异丢失座位或准备状态。

## 信任与可用性边界

- 棋局采用房主权威模型。客方能验证状态结构、手番、落子和胜负，但恶意房主仍可能发布任意通过这些约束的合法快照。
- 房间公开且允许开放加入，房间 ID 等同于入场凭证；应用不提供额外口令层。
- 房主掉线时没有自动选主或故障转移；恢复依赖原房主重新上线及 Room 历史中的最新合法快照。

## 权限

- `storage`：本地战绩与最近房间恢复信息。
- `ui:theme`、`ui:confirm`：跟随宿主主题，以及离开/认输确认。
- `federation:read`、`federation:write`、`federation:message`：身份、房间管理与结构化棋局消息。

未获得联邦权限时，联机入口会停用，本地双人模式仍可使用。Widget 当前不承载联邦处理器，因此本应用只提供 Page。

复制房间 ID 优先使用 Clipboard API；opaque-origin 沙箱拒绝时自动回退到同步复制命令。
