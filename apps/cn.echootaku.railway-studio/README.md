# 轨路工坊 / Railway Studio

轨路工坊是一个离线 Myriad Tapp，用同一份版本化工程完成铁路线路图编辑和车票生成。线路几何负责画面，交通边负责路线、时间与票价；两者通过稳定 ID 关联，不维护另一份硬编码站点表。

## 主要能力

- 导入 PNG、JPEG、WebP 背景；除文件 MIME 与解码结果外还核对真实二进制签名。Canvas 与 SVG 共享场景坐标和视口变换，背景、线路、站点与文字始终对齐。
- 在标题栏直接编辑工程名称；Enter 或失焦保存，Escape 取消，名称同时用于工程元数据和导出文件名。
- 选择、平移、缩放、满幅世界网格、带开关反馈的吸附、撤销/重做；`Alt` 二点绘制可建立带贝塞尔控制柄的曲线。
- “二点成段”通过两次点击生成一段线路；“多段路径”连续添加途径点，以双击或 `Enter` 完成，`Backspace` 回退一个草稿点，`Escape` 取消。
- 新线路可吸附到既有线路节点、连接点或站点；共享连接点的线路和站点会一起移动，线路端点可直接升级为站点。
- 编辑线路节点和控制柄；移动节点或共享连接点时控制柄保持相对位置，单独拖动控制柄才改变曲率。站点与文字也可拖动，并可配置名称、颜色、线宽/半径/字号。
- 显式建立站点之间的单向或双向交通边，并配置线路、距离和预计分钟数。
- 为线路、站点或文字配置开始时间、持续时间、缓动和 `draw` / `fade` / `pulse` 效果；也可从两个已放置站点创建有方向的行程描边，按真实交通边顺序经过支线和换乘。
- 行程动画默认保留原路线并在上方逐段高亮；关闭“显示原路线”后只遮住本次行程经过的精确片段。反向行程会反转路径、曲线控制柄和到站顺序。
- 车票起终点既可选择已有站点，也可直接输入新站名；尚未绘制的需求进入可横向滚动的“待绘制路线”栏，并区分缺少两端、缺少单端和已放置但未连通。
- 从路线栏直接放置整条路线：既有站点自动固定为端点，缺失站点随点击落位，途径点形成多段路径；一次操作原子建立站点位置、线路几何和交通边，并可整步撤销。
- 车票从当前工程选取起终点，以确定性最短路生成线路分腿、时间、距离、换乘和票价说明；路线未完成时不会伪造车票，而是保存为待绘制需求。
- 自动保存到当前 Tapp 用户空间；支持版本化 JSON 导入/导出和静态 SVG 导出。

## 工程格式

工程根字段固定为：

```json
{
  "schema": "myriad-railway-project",
  "version": 4,
  "meta": {},
  "canvas": {},
  "settings": {},
  "assets": [],
  "junctions": [],
  "lines": [],
  "stations": [],
  "network": { "edges": [], "routeRequests": [], "farePolicy": {} },
  "texts": [],
  "timeline": { "durationMs": 6000, "tracks": [] },
  "extensions": {}
}
```

- `junctions[]` 是显式几何连接点；线路点和已放置站点通过可选 `junctionId` 绑定，绑定对象以连接点坐标为准。
- `stations[].placement` 为 `null` 时表示车票已创建、但尚未在图上落位的规划站；已放置时保存 `x`、`y` 和可选 `junctionId`。
- `lines[].paths[].points[]` 保存视觉几何与绝对贝塞尔控制柄；新路径首尾自动建立连接点，途径点在被连接时建立连接点。
- `network.edges[]` 保存可通行拓扑，引用站点和线路稳定 ID，可选引用几何路径。
- `network.routeRequests[]` 保存待绘制需求，只记录起终点站 ID、班次、可选指定线路、创建时间和忽略状态，不保存游戏昵称。
- `timeline.tracks[]` 同时支持对象轨道和 `targetType: "route"` 的行程轨道。行程轨道保存有方向的交通边快照、样式、时序和 `showBaseRoute`，几何仍通过 `geometryRef` 引用线路路径，不复制第二份 SVG 数据。
- 未声明版本的受支持草稿会逐级迁移到 v1、v2、v3、再到 v4；v1→v2 不会根据重合坐标猜测连接，v2→v3 将原站点坐标包装为显式 `placement`，v3→v4 保留全部对象动画且不猜测其起终点。未来版本、外部 schema、重复 ID、悬空引用和超限结构均封闭失败。
- 导入在完整解析、复杂度检查、迁移与引用校验成功后才替换当前工程；嵌入背景的 Data URL 必须包含完整标准 Base64，且媒体类型与资产声明一致。

## 背景图与大图

- 文件上限为 32 MiB；解码后单边不超过 16384 像素，总像素不超过 4000 万。
- 不超过 5 MiB 的图片以 Data URL 嵌入便携工程。
- 更大的合规图片使用 `detached` 资产：工程只保存名称、MIME、尺寸、字节数和 SHA-256，本次会话保留预览；重新打开工程后需要用户重新选择原图。
- 画布保持有界逻辑尺寸，不按原图像素创建超大 Canvas，降低大图内存峰值。

## 路线与票价

待绘制路线检测包含四种非就绪状态：

- 起终点均未放置：路线栏提供整条路线，用户依次点击起点、途径点和终点。
- 仅一端未放置：既有端点固定，只需放置缺失站点；完成后自动连接。
- 两端都已放置但未连通：两端固定，可直接完成直连，也可添加途径点。
- 指定线路未连通：只按指定线路的交通边判断，不会误用其他线路绕行。

路线项可以本次忽略并从“已忽略”筛选恢复。放置中可用按钮或 `Enter` 完成、按钮或 `Escape` 取消；取消不会产生工程修改。

路由以预计分钟数为首要成本；时间相同时依次减少换乘、距离，并用稳定交通边 ID 决胜，因此相同工程会产生确定结果。连续同线路边合并为一段行程。

## 有方向行程动画

- “动画”页签只列出已经放置的站点；选择起终点后先预览由当前交通网络计算的线路、距离、时间和换乘，点击应用才写入一条可撤销历史命令。
- 保存后的轨道固定有序交通边快照。工程后来增加更短路线时不会静默改道；需要时由用户点击“重新计算路线”。
- 时间轴按各片段实际几何长度分配进度，起点先显示，中途站和终点按抵达顺序显现；拖动时间轴与连续播放得到相同的确定帧。
- 删除被行程轨道引用的站点、交通边、线路或路径会被阻止，须先移除或重新计算动画，避免产生悬空工程。
- 宿主要求减少动画时直接显示最终行程状态；Page 暂停、恢复和销毁继续使用既有生命周期控制。
- 静态 SVG 始终导出完整基础线路图，不包含时间轴覆盖层、遮罩或可执行动画。

默认票价以最小货币单位计算：

```text
原价 = 基础价 + ceil(总距离 / 距离步长) × 每步价格 + 换乘数 × 换乘费
总价 = 向上取整到 roundingMinor
```

票面同时展示各项金额，避免无法解释的黑盒价格。到达跨越午夜时显示 `+1` 等完整日偏移，票号格式为 `RS-YYYYMMDD-<12 hex>`。

## 保存与错误恢复

自动保存使用带校验和的分块快照：先写候选修订、逐块读回并核验，再切换 active 指针；候选写入或读回失败时保留旧活动修订。保存请求按调用顺序串行提交，较早请求不会覆盖较新的 active 指针；提交后的旧修订清理失败也不会误报新快照保存失败，后续保存会再次清理。默认分块小于单值存储上限，总预算预留在宿主配额以内。恢复期间若用户新建或导入工程，迟到的恢复结果不会覆盖用户操作。

## 导出边界

- JSON：通过 `Tapp.file.download` 导出字符串内容，可再次导入。
- SVG：通过同一宿主接口导出静态线路图；动画轨道不会伪装成动态 SVG 或视频。
- PNG：当前 generated contract 的下载参数只接受字符串，没有可证明的二进制文件出口。应用只显示限制和“导出 SVG 后转换”的合规替代方案，不调用 `<a download>`、Blob URL 或其他浏览器下载逃逸。

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `storage:read` | 恢复当前用户空间中的工程快照 |
| `storage:write` | 事务式自动保存工程快照 |
| `ui:theme` | 跟随宿主亮色/暗色主题 |
| `ui:confirm` | 新建工程前确认替换当前工程 |

应用不请求网络权限，不加载 CDN，不上传地图、昵称或工程内容。文件只由用户通过本地文件选择器导入。宿主未提供确认能力时，新建操作会失败关闭并保留当前工程。

## 本地校验

在仓库根目录使用仓库随附 CLI 与本机 `D:\SDK` Node.js：

```powershell
node scripts/validate-app.mjs --app cn.echootaku.railway-studio
node scripts/validate-previews.mjs --app cn.echootaku.railway-studio
node tapp-cli/bin/myriad-tapp.mjs check apps/cn.echootaku.railway-studio --json
node scripts/sync-index.mjs validate --app cn.echootaku.railway-studio
```

自动校验和 `.tapp` 打包不等于真实 Myriad 验收。仍需在真实宿主中回归主题/语言、生命周期、Storage 配额、文件选择和下载交互。
