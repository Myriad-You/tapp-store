# 今日简报

把 Brew 阅读队列整理为一份专注的每日简报，并将最近一次结果同步到主页小组件。

## 功能

- 未读、收藏和全部内容筛选
- 来源、时间和摘要速览
- Myriad AI 三点摘要
- 2×2、4×2、4×4 首页小组件
- 最近一次简报本地缓存

## 访问边界

- 访客：读取公开 Brew 内容、切换简报栏目。
- 登录用户：在站长下放对应权限后可使用 AI 摘要，但不会修改公共简报快照。
- 管理员：修改安装级设置、刷新公共简报、批准权限并管理主页小组件。

所有权限最终由 Runtime Grant 和宿主后端再次校验，界面中的角色提示不是安全边界。

Playground 临时预览不会注册 `Tapp.brewList` handler；完整数据读取需安装后运行。
