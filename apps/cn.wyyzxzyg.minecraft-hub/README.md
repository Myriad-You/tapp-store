# Minecraft 服务器与 Wiki

普通玩家可直接使用的 Minecraft 工具 Tapp。

作者：**我願一直向著陽光.℡**

## 功能

- 查询 Java 版与基岩版服务器
- 展示在线状态、MOTD、版本、人数、玩家、软件、IP 与端口
- 按用户独立保存最近查询
- 配置多台首页展示服务器并自动轮播
- 自定义轮播间隔和服务器状态自动检测间隔
- 手动选择 Java 版或基岩版，自动联网获取正式版、快照版或预览版列表
- 选择具体版本后自动显示发布日期、通道和平台信息
- 直达 Java 原版服务端、Paper、Fabric、Modrinth 与 CurseForge
- 直达基岩版独立服务端、创作者文档与官方示例
- 搜索中文 Minecraft Wiki 并显示摘要
- 点击搜索结果直接跳转到中文 Minecraft Wiki 条目
- 支持深色模式与移动端

## 首页小组件

1. 打开该 Tapp 的“应用设置”。
2. 在“我的服务器”中填写服务器，格式为 `java|地址` 或 `bedrock|地址`；多台服务器使用逗号分隔。
3. 设置轮播间隔（3–300 秒）和自动检测间隔（15–3600 秒），然后保存设置。
4. 返回 Myriad 首页，添加“Minecraft 服务器状态”小组件。若尚未配置，小组件会提示“请在 Tapp 设置中添加服务器”。

配置多台服务器后，小组件会按照轮播间隔循环切换，并显示当前序号。每台服务器的缓存超过自动检测间隔后才会重新查询，避免重复请求。旧版单服务器配置会自动迁移，不需要重新填写。

服务器状态由 mcsrvstat.us v3 提供。Java 与基岩版版本列表通过无重定向的小型 JSON 接口分别获取，并提供私有缓存与内置目录兜底。Wiki 内容来自社区维护的中文 Minecraft Wiki。本插件与 Mojang Studios、Microsoft、Minecraft Wiki 及查询 API 服务方均无隶属关系。
