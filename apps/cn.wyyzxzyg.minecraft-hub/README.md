# Minecraft 服务器与 Wiki

普通玩家可直接使用的 Minecraft 工具 Tapp。

作者：**我願一直向著陽光.℡**

## 功能

- 查询 Java 版与基岩版服务器
- 展示在线状态、MOTD、版本、人数、玩家、软件、IP 与端口
- 收藏服务器并保存最近查询
- 配置多台首页展示服务器并自动轮播
- 自定义轮播间隔和服务器状态自动检测间隔
- 搜索中文 Minecraft Wiki 并显示摘要
- 复制 Wiki 原文地址
- 支持深色模式与移动端

## 首页小组件

1. 进入 Tapp 的“我的服务器”页面。
2. 在“首页小组件设置”中选择 Java 版或基岩版，填写地址并点击“添加服务器”。可以重复添加多台服务器。
3. 设置轮播间隔（3–300 秒）和自动检测间隔（15–3600 秒），然后保存间隔设置。
4. 返回 Myriad 首页，添加“Minecraft 服务器状态”小组件。

配置多台服务器后，小组件会按照轮播间隔循环切换，并显示当前序号。每台服务器的缓存超过自动检测间隔后才会重新查询，避免重复请求。旧版单服务器配置会自动迁移，不需要重新填写。

服务器状态由 mcsrvstat.us v3 提供。Wiki 内容来自社区维护的中文 Minecraft Wiki。本插件与 Mojang Studios、Microsoft、Minecraft Wiki 及查询 API 服务方均无隶属关系。
