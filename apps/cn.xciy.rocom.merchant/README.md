# 洛克王国情报台

洛克王国情报台是一个用于查看远行商人信息的 Myriad Tapp，提供页面视图和桌面小组件，方便持续关注商人轮次、换货倒计时、活动行程与官方公告。

## 功能

- 远行商人：展示当前轮次、倒计时、货单与关注清单命中。
- 活动行程：整理近期活动信息，便于规划每日路线。
- 王国公告：聚合官方公告与更新提醒。
- 精灵图鉴：支持按名称或 ID 检索图鉴线索。
- 小组件：支持 2x2、4x2、4x4 三种尺寸。

## 使用前准备

由安装 owner 或管理员在 Tapp 详情页的凭据（credentials）中填写 WeGame API Key。凭据仅会由宿主附加到声明的 WeGame 请求头，沙箱、设置和访客均无法读取。

## 权限说明

- `network:fetch`：请求 WeGame 数据接口。
- `storage:read` / `storage:write`：缓存最近一次成功同步的数据，便于离线或接口异常时展示。
- `widget:register`：注册桌面小组件。

## 文件

- `manifest.json`：Tapp 元数据、设置项、接口与小组件声明。
- `main.js`：后台同步、页面交互与小组件数据渲染。
- `page.html`：主页面模板。
- `styles.css`：主页面与小组件统一样式。
- `templates/`：2x2、4x2、4x4 小组件模板。
