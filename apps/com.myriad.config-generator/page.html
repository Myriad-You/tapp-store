Compose · .env · Nginx · 部署说明

说明 按面板生成 Compose / .env / Nginx 与部署步骤。密钥勿提交。

面板

部署面板
1Panel：docker-compose.yml →「容器 / 编排」；.env →「环境变量」。站点整站反代到 HTTP_BIND:HTTP_PORT。

域名

不要带 https://。会写入 BASE_URL/FRONTEND_URL（联邦 Actor URL）；外层 Nginx 须整站反代到 proxy，勿只反代 /api。

数据库

部署方式
写入 MYRIAD_DB_MODE=bundled|external。外置时 updater 不快照数据库，备份自负。
主版本 18–20（与当前 alpine 镜像线一致） 内置镜像 postgres:VERSION-alpine，主版本 ≥18
容器访问宿主机上的库：常用 host.docker.internal（Docker Desktop）、宿主 IP，或 docker bridge 网关（如 172.17.0.1）。托管库填公网/VPC 主机名即可。
如果你的数据库同为容器但是与 myriad 不在同一个子网，你可能需要这个选项。对于 1Panel 部署，它通常为 1panel-network。这可能会增加后端容器的安全风险。
小写字母/数字/_，字母开头
写入 DATABASE_URL 时会对密码做 URL 编码

密钥

写入 .env（未加引号）。仅允许 A-Za-z0-9_-，≥32 位；禁止换行 / 空格 / # / =。勿提交、勿外传。

updater / gateway / guard
backend ↔ gateway
首次打开站点创建所有者时要填。先点「复制」存下来，或从生成结果的 .env 里找 MYRIAD_SETUP_SECRET。不要发到群里。

镜像 tag

Docker Hub versioned tag，禁止 :latest。生产可写 vX.Y.Z@sha256:<64hex> pin digest。
