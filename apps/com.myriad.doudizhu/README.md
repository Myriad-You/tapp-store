# 斗地主 2.3.3

面向 Myriad Page 沙箱从零重建的三人单机斗地主。无需账号、后端或网络权限；两名电脑玩家只读取自己的手牌和公开牌局信息。

## 对局能力

- 一副 54 张牌随机洗牌，三家各 17 张，保留 3 张底牌。
- 叫地主、抢地主、无人叫时重新发牌。
- 单张、对子、三张、三带一、三带二、顺子、连对、飞机、飞机带单、飞机带对、四带二、四带两对、炸弹和王炸。
- 连续两家不出后清空桌面，由最后出牌者重新领出。
- 默认 20 秒回合计时；超时自动不出或选择最小合法牌。
- 简单、标准、困难三档本地 AI；困难档会评估牌组结构、剩余手数、上下家威胁与农民配合。
- 10/15/20/30 秒或不限时、超时托管、暂停与后台自动暂停。
- 提示轮换、点击选牌、横向滑动连续选牌、双击出牌、两种排序、动画降级与纯本地 Web Audio 合成音效。
- Manifest `settings` 只提供安装级默认值；玩家覆盖值、未完成牌局、累计胜负与积分均使用按主体隔离的 `Tapp.storage` 保存。
- Page 与小组件优先使用 `Tapp.context.getUser()` 显示当前 Myriad 用户名和头像；不安全或不可加载的头像自动回退为名字首字。
- 提供 1×1、2×2 与 4×2“今日斗地主”小组件，以互不重叠的响应式网格展示当日胜负、胜率、净积分；最近一局获胜显示地主形象，失败显示农民形象。
- 页面文案通过 `Tapp.i18n` 提供简体中文、英语和日语，界面外壳跟随宿主主题、安全区域与缩放契约。
- 移除重复的页内应用导航与网页全屏按钮，由 Myriad 宿主负责导航、设置入口和全屏切换。
- 桌面、笔记本、平板和手机横屏响应式布局；宿主全屏后装饰背景铺满 Tapp 可用区域，HUD、底牌与玩家信息作为独立内容层遵循宿主安全区，且不参与页面高度计算。

## 测试

```powershell
node tapp-cli/bin/myriad-tapp.mjs check apps/com.myriad.doudizhu --json
```

游戏采用无构建运行架构：规则、状态机和 AI 是独立 Page 模块，小组件通过共享的 `stats:v2` 存储读取当日战绩。
